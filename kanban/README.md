# Strata board

`backlog/` not yet detailed. `todo/` ready, criteria written. `in-progress/` being worked,
keep it to one or two. `review/` implementation complete, awaiting Julien. `done/` shipped.

Files are named `[PRIORITY]-[COMPONENT]-[description].md`.

Priority: `P0` critical path, `P1` early, `P2` standard, `P3` nice to have.
Component: `ARCH` shape and tooling, `TERRAIN` repo feed and hierarchy, `LAYOUT` placement,
`DRAW` rendering and motion, `WEATHER` agent feed, `NAV` camera and keyboard, `IDE` the
VS Code adapter, `DOCS`.

Each card carries: Description, Acceptance Criteria, Technical Notes, Definition of Done.
A card moves column when its own Definition of Done says so.
